Empirical Scaling Dynamics on Non-Trivial Tasks

Counterfactual Protocol Definitions
Experimental conditions required to reject artifacts
Condition A (Cooperative Team): Full inter-agent communication, structured topology, joint consensus.
Condition B (Independent Pass@4): 4 isolated agents with independent attempts; external verifier selects the best output. Controls for sampling diversity.
Condition C (Iso-Budget Single Agent): Single agent allocated the full 4x token budget with test-time reflection iterations. Controls for compute scaling.
Condition D (Scrambled Communication): Team topology with randomized message content. Verifies whether semantic information exchange drives performance.
